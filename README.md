# ✦ Youtube-Clone

Um clone nostálgico da interface clássica do YouTube (cerca de 2010), desenvolvido para recriar a experiência visual e interativa da época.

## ✧ Sobre o Projeto

Este projeto simula o layout antigo do YouTube, focado na era de ouro dos videoclipes (2000-2010). Ele foi construído utilizando tecnologias web padrão sem frameworks pesados, focando na estrutura e estilização manual.

## ⊹ Funcionalidades

- **Reprodução de Vídeo**: Player Híbrido que tenta rodar vídeos locais e usa o YouTube como fallback.
- **Interatividade**:
  - Botões de **Like** e **Dislike** com contadores funcionais.
  - Botão de **Inscrever-se** com alternância de estado.
  - Botão de **Compartilhar** que copia o link para a área de transferência.
- **Comentários**: Sistema para postar novos comentários e responder aos existentes.
- **Playlist Lateral**: Lista de vídeos sugeridos carregada dinamicamente de um arquivo JSON.
- **Design Retrô**: Estilização fiel com CSS puro, incluindo gradientes e fontes da época.
- **Acessibilidade**: Suporte a navegação por teclado e leitores de tela.

## ⟡ Tecnologias

- HTML5
- CSS3 (com uso de variáveis CSS)
- JavaScript (Vanilla)
- YouTube API
